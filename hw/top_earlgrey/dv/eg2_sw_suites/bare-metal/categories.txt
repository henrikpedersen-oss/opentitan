# The bare-metal suite's test categories, for its report. One line per pattern:
#   <pattern> <category>
# The pattern is an awk regular expression matched against the test name; the first matching line
# gives the category, and the report lists the categories in this order. A name that matches no line
# goes to "Other". Categories are "<area>: <block>", small enough to read at a glance.
#
