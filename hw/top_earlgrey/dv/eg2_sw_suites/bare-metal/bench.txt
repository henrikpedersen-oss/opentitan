# What the chip bench does for a test, given to eg2sim instead: one line per test,
#   <test> <eg2sim arguments>
# --sym <symbol>=<value>[:<bytes>] writes the test image as the bench's sw_symbol_backdoor_overwrite
# does; --stim <key>=<value> drives the peripheral models as the bench's agents do (the keys are in
# peripherals/pinmux/sw/systemc-model/eg2_periph_stim.h; {sym:<symbol>:<length>} sends bytes of the
# test image, {rep:<hex byte>:<count>} a repeated byte). Each line says which bench sequence it
# stands in for. No spaces inside an argument: write a space in a log message as %20. A stimulus
# at a point of the run: --stim <key>=<value>@<point>[@<point>...][+<delay>], the points log:<message>
# (<prefix>* for any message starting so), status:<InTest, InWfi, InBootRom, ...>, event:<name>, wfi,
# lowpower;
# a value list v1,v2,... gives the n-th time its n-th value; {n} is the n-th number of the log
# message a point matched (eg2sim.cc, TrigStim).
# USB SETUP reception (chip_sw_usbdev_setuprx): the sim_dv image compiles out the FPGA-only
