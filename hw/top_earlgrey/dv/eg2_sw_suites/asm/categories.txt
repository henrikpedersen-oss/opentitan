# The assembler suite's test categories, for its report. One line per pattern:
#   <pattern> <category>
# The pattern is an awk regular expression matched against the test name; the first matching line
# gives the category, and the report lists the categories in this order. A name that matches no
# line goes to "Other".

^rvt\.rv32uc\.            riscv-tests: rv32uc (compressed)
^rvt\.rv32mi\.            riscv-tests: rv32mi (machine mode, traps, CSRs)
^arch\.I\.                Architecture tests: I (base integer)
^arch\.M\.                Architecture tests: M (multiply and divide)
^arch\.C\.                Architecture tests: C (compressed)
^arch\.B\.                Architecture tests: B (Zba, Zbb, Zbc, Zbs)
^arch\.Zifencei\.         Architecture tests: Zifencei
^arch\.privilege\.        Architecture tests: privilege (misaligned, ecall, ebreak)
^rand\. EG2 constrained random framework
