# The CHERIoT RTOS suite's runs: one firmware image each, on eg2sim --board rtos_soc. A run gives
# many tests, one per check the firmware reports on its UART (README.md). Lines:
#   <run> <image> [<eg2sim arguments>]   the image: a path in the eg2_top_verification
#                                        checkout (its firmware build: make rtos-firmware there),
#                                        or nix:<package>/<path>, a package of its flake
#   <run> must-print <count> <regex>     the run's verdict needs exactly <count> UART lines matching
#                                        <regex> (extended regular expression, colour codes removed);
#                                        a run with such lines needs no "All tests finished"
#   <run> must-fail <check> ...          a mutation run: these checks must fail, and only they are
#                                        tests of the run (a pass means the suite missed the break)

# Mutations: the model with one check broken (eg2sim --mutate, as the SoC's +cheriot_rtos_mutate),
# so the suite shows it notices. barrier_none: the load barrier never revokes; tbre_no_inval: the
# hardware revoker sweeps but never clears a tag; dbg_lock_open: the debug-access gate lets the
# debug module's bus writes through while debug access is disabled.
